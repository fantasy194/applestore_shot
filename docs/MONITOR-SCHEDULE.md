# 自动监控每日检测时段（0.1.16）

“自动监控”和 DUO 页面中的门店监控共用一个服务器端设置。默认关闭时段限制，全天按原检查间隔运行。

## 设置示例

1. 如果正在监控，先点击“停止监控”。
2. 勾选“启用每日检测时段”，选择“时段内暂停”。
3. 开始时间设为 `01:00`，结束时间设为 `05:00`。
4. 点击“保存并开始监控”。每天北京时间 01:00 起暂停自动检测，05:00 恢复并查询新库存。

选择“仅时段内检测”时，则只在所设时段内查询。所有时间固定采用 `Asia/Shanghai`（北京时间），与手机、电脑或 Docker 宿主机的本地时区无关。开始时刻包含、结束时刻不包含；支持跨午夜，例如 `22:00–05:00`。启用时开始与结束不能相同；需要全天检测时关闭时段限制。

暂停时界面显示“按时段暂停”和下次恢复时间，监控任务仍保持运行，可以随时停止。关闭页面不会停止服务器调度；服务重启后，如果之前开启监控，恢复时先重新判断当前时段。主动点击停止仍保持原有的“重启后不自动开启”规则。

## 查询与购买边界

时段限制只用于自动库存检测。暂停状态下不发起自动库存查询，自动代理池暂时停用；保留匿名手动门店查询服务。单次手动检查不受每日时段规则限制，仍遵循原有的查询互斥规则。

边界前已经发出的只读请求允许有界收尾；越过暂停边界的响应不作为新库存发布，也不生成新有货历史或自动入队信号。恢复时进行新查询，不补跑暂停期间的轮次，不把旧样本重新标为新鲜。

已接收到有货信号并入队的购买继续按原队列规则执行，进行中的购买不受时段暂停影响。只保存时段、间隔或代理配置，不会清除未执行购买已经获得的库存信号；变更购买目标或撤销购买授权仍沿用原有核验规则。提交未知、手动取消及旧失败任务的处理保持既有边界。

## 配置与验证

设置与其他库存配置一起保存在服务器的加密配置中：

```json
{
  "schedule": {
    "enabled": true,
    "mode": "exclude",
    "start": "01:00",
    "end": "05:00",
    "timezone": "Asia/Shanghai"
  }
}
```

`mode` 为 `exclude`（时段内暂停）或 `include`（仅时段内检测）。旧配置缺少 `schedule` 时按全天检测兼容；保存请求省略该字段时保留原有时段设置。暂停事件不携带有效库存目标或伪造检查时间，也不被队列视为目标移除。

离线回归覆盖边界、跨午夜、时钟变化、取消、配置保存与兼容、代理停用和恢复、请求/客户端切换跨界，以及队列授权保持。界面测试使用不同本地时区，覆盖保存恢复、无效时间、暂停状态及 320/390px 布局。这些证据证明本地调度行为，不代表真实 Apple 库存、订单创建或付款成功。
