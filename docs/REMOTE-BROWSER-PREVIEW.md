# 官网远程画面后台刷新

手机和浏览器中的“Apple 官网窗口”在后台读取新截图并解码，完成后再替换当前画面。读取和解码过程中继续显示上一帧，短暂无截图或请求失败不会反复移除画面、重建输入框或清空尚未发送的内容。

同一任务在“执行中”和“需要操作”之间切换时继续使用同一个预览。窗口真正结束、任务结束或切换到其他账号 / 任务时，清除原画面和未发送输入；迟到的截图和请求结果不能覆盖新任务。

点击和滚动使用实际显示帧的序号与原始尺寸，按下到释放之间保持显示画面不变。没有有效新画面时仍显示上一帧；超过现有五秒时效后暂停向官网发送操作，等待有效画面恢复，输入框仍可继续编辑。刷新不放宽任务归属、画面时效或服务端输入检查。

输入内容仍只在内存中暂存，发送后清空，不写入浏览器存储、任务日志或截图缓存。Apple 密码、验证码和官网安全验证继续由用户在当前任务中处理。

## 验证

`tests/ui/remote-browser.spec.ts` 使用本地合成截图与桥接 fixture，验证连续画面更新、空帧、慢请求、图像解码、输入焦点、点击坐标、过期帧及任务切换。测试不访问 Apple，不填写真实密码或验证码，也不创建订单。

生产构建及双架构容器发布沿用 [GHCR 工作流](../.github/workflows/ghcr.yml)。Pi 更新前先确认账号任务状态，并保留现有 `/data` 挂载和 Web 密码；镜像健康与预览回归不能作为真实 Apple 登录成功的证明。
