# 界面统一与手机适配

2026-10-23 对照 [DESIGN.md](../DESIGN.md) 审查。此次采用共享控件、对齐边缘、提高列表可扫读性和至少 44px 手机触摸区域的原则。所有浏览器截图均使用隔离的合成账号、库存事件、队列和订单；没有访问真实 Apple 账号。

## 审查与修改

| 范围                       | 首轮问题                                             | 修改结果                                                                                           |
| -------------------------- | ---------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 下拉选择                   | 自定义下拉与系统选择器混用，触摸菜单可能因失焦被关闭 | 全部复用 `SelectField`，保留键盘定位、选中标记、长选项换行和可视窗口内定位；验证触摸滚动后仍可选择 |
| 数量、并发、重试、代理容量 | 系统数字框的小型加减箭头不适合手机                   | 共享 `NumberField`，独立加减按钮、数字键盘和直接编辑；保留范围、整数步长和禁用状态                 |
| 数字输入状态               | 清空或越界输入不能误用上一个值执行操作               | 无效草稿保留在输入框内并阻止操作；失焦后在界面明确恢复或归一化，表单 Enter 仍校验                  |
| 最近有货                   | 三列卡片以门店为主，时间和型号不突出                 | 分隔列表先显示时间及型号，补充 SKU 和门店；同一时间、同一型号的不同门店记录分别保留                |
| 监控门店                   | 外层面板再嵌套大卡片，重复留白                       | 统一分隔行，桌面对齐门店、商品、库存状态，抢购设置按需展开                                         |
| 队列与日志                 | 一条任务占用独立大卡片，详情与日志操作分散           | 统一分隔行与操作区，保留待付款、提交未知、账号阻塞及当前任务入口                                   |
| 概览与视觉                 | 低信息量的三块统计卡片，圆角及控件行高不统一         | 合并为紧凑统计条，统一 8px 圆角及控件高度                                                          |
| 320px 窄屏                 | 页签溢出、日期控件固有宽度挤出页面、商品表格挤成窄列 | 页签等分并约束表单宽度；商品、DUO、订单按行展示，保留完整信息和操作                                |

日期、时间保留系统适合手机触摸的输入方式。账号勾选、授权、订单确认、真实库存判断、队列 FIFO、提交未知停止规则及按需加载接口保持现有语义。
